# 시드 데이터

## 종류

- development: Swagger와 화면 연동을 위한 읽기 쉬운 샘플
- test: 자동 테스트를 위한 최소 고정 데이터
- reference: 나이·성별별 영양소 CSV

부트스트랩은 DB 연결과 멱등 실행 순서를 보장하는 시드 레지스트리를 제공한다.
F-2.2부터 제품 카테고리를 레지스트리에 등록하며, 제품·의약품과 영양소 기준 데이터는
각각 승인된 카탈로그 기능 PR과 CSV 기준 기능 PR에서 추가한다. 아직 승인되지 않은
제품 데이터를 임의로 만들지 않는다.

## F-2.2 제품 카테고리

| 고정 UUID | slug | 이름 | 활성 | 정렬 순서 |
| --- | --- | --- | --- | --- |
| `21000000-0000-4000-8000-000000000001` | `vitamin` | 비타민 | 예 | 10 |
| `21000000-0000-4000-8000-000000000002` | `protein` | 단백질 | 예 | 20 |
| `21000000-0000-4000-8000-000000000003` | `omega-3` | 오메가3 | 예 | 30 |

- 자연 키는 `slug`다. 반복 실행하면 이름·활성·정렬 순서를 승인 값으로 복원한다.
- `all`·`전체`는 필터 미적용을 나타내는 API 가상 항목이므로 DB에 시드하지 않는다.
- 카테고리별 제품 연결은 F-2.3에서 추가한다.

## 필수 데이터

- 제품 카테고리(F-2.2 완료)
- 게시된 영양제
- 게시된 의약품
- 제품별 단위와 총 용량
- 영양제별 단위당 성분
- 전문가 코멘트
- 활성 외부 구매 링크
- 영양소 기준 CSV

## 규칙

- 반복 실행해도 중복되지 않는다.
- 자연 키 또는 고정 식별자를 명시한다.
- 실사용자, 실제 이메일, 실제 건강정보를 포함하지 않는다.
- 테스트는 특정 생성 순서나 현재 시간에 의존하지 않는다.
- 제품 변경이 기존 CareItem 스냅샷을 바꾸지 않는 사례를 포함한다.
- 의약품이 영양소 합계에 포함되지 않는 사례를 포함한다.

## 검증

- 필수 필드
- 중복 키
- 음수 또는 0 이하 수량
- 지원하지 않는 단위
- 중복·겹침 나이 구간
- 외부 구매 URL 형식
- 게시 상태와 참조 무결성
