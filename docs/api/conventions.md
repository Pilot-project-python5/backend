# API 규약

## 기본 형식

- 기본 경로: /api/v1
- 미디어 유형: application/json
- JSON 필드 이름: snake_case
- 식별자: 내부 형식을 해석할 수 없는 값으로 취급하며 클라이언트는 형식을 추론하지 않는다
- 날짜: YYYY-MM-DD
- 일시: 시간대를 포함한 ISO 8601

## 동작

- 인증이 필요한 API는 미인증 요청에 401을 반환한다.
- 다른 사용자의 리소스는 존재 여부를 노출하지 않도록 404 또는 정책상 정의한 응답을 일관되게 사용한다.
- 유효성 오류는 필드 단위 코드를 제공한다.
- 생성 성공은 201, 삭제 성공과 본문 없음은 204를 기본으로 한다.
- 목록 API는 일관된 페이지네이션과 정렬 형식을 사용한다.

## 멱등성

- AI 질문은 2차에서 client_request_id를 사용한다.
- 알림은 대상, 종류, 기준일과 채널 조합으로 중복을 방지한다.
- 시드는 고정된 자연 키 또는 안정적인 식별자를 사용한다.

## OpenAPI

- 모든 엔드포인트에 summary와 operation_id를 부여한다.
- 요청, 성공 응답과 주요 오류 예시를 포함한다.
- enum과 상태값의 의미를 설명한다.
- 프론트엔드가 Swagger만으로 연동할 수 있어야 한다.
