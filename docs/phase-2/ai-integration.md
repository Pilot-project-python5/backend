# 2차 AI 연동 경계

AI 코칭은 다른 개발자가 1차 MVP 이후 구현한다.

## 허용된 조회

- 인증된 사용자의 최소 건강 프로필
- 현재 활성 복용 제품과 계획
- 계산된 영양소 현황
- 게시된 큐레이션 제품
- 검증된 성분 기준 데이터

## 제한

- AI 모듈이 auth, catalog, care 테이블을 직접 수정하지 않는다.
- 공개 애플리케이션 서비스 또는 명시된 API 계약을 사용한다.
- 필요한 최소 건강정보만 전달한다.
- 의료 진단과 처방을 생성하지 않는다.
- 허용된 제품 ID와 성분 ID를 응답 후 검증한다.

## 2차에서 결정할 항목

- 같은 저장소의 coaching 모듈 또는 별도 서비스
- LLM 공급자와 모델
- 스트리밍 여부
- 건강정보 동의와 철회
- 세션과 대화 보관 기간
- 시간 초과, 재시도와 비용 제한
- 안전 분류와 검수 책임
- 답변 근거와 버전 추적

1차에서는 빈 coaching API나 가짜 AI 응답을 만들지 않는다.
