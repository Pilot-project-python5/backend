# 2차 이메일 공급자 연동 경계

## 1차

- 로컬 SMTP 수신함으로 이메일을 확인한다.
- 자동 테스트는 FakeEmailSender를 사용한다.
- F-3.12는 Notification별 EmailDelivery와 수신 주소 스냅샷을 저장한다.
- PENDING·SENDING·RETRY·SENT·FAILED와 최초 포함 최대 3회·고정 5분 재시도를 적용한다.
- 로컬 SMTP에는 제공자 멱등 키가 없어 전송 성공 직후 DB 기록 전 프로세스 종료 구간은
  중복 가능성이 남는다.

## 2차

- 운영 공급자 선택
- 제공자 멱등 키 또는 transactional outbox
- 발신 도메인과 인증
- 반송과 스팸 신고 처리
- 재시도와 실패 메시지 보관 정책
- 개인정보와 보관 기간
- 전달률과 실패 모니터링

인증번호, 토큰과 비밀번호를 이메일 로그나 애플리케이션 로그에 남기지 않는다.
