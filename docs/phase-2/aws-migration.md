# 2차 AWS 이전 경계

1차에서는 AWS 서비스를 선택하거나 연결하지 않는다. 다음 계약을 지켜 2차에서 어댑터와 설정 중심으로 전환한다.

## 유지할 특성

- PostgreSQL 스키마와 마이그레이션
- 환경변수 기반 설정
- 무상태 API
- 상태 확인
- 외부 저장소 인터페이스
- 작업자의 멱등 처리

## 2차에서 결정할 항목

- 실행 서비스
- 관리형 PostgreSQL
- 객체 저장소와 CDN
- 스케줄러와 대기열
- 비밀정보 관리자
- 로그, 지표, 추적과 경고
- 백업, 복구와 배포 롤백

AWS 리소스 이름이나 SDK 객체를 도메인 계층에 노출하지 않는다.
