# ADR-0002 단일 모델 SDD

- 상태: accepted
- 날짜: 2026-08-10

## 배경

프로젝트는 Codex 단일 모델로 개발하며 기능 단위 PR과 반복 가능한 하네스가 필요하다.

## 결정

- 멀티에이전트 기능을 프로젝트 설정에서 비활성화한다.
- 기능 하나마다 Feature Packet을 작성하고 사용자 승인 후 구현한다.
- 한 PR은 하나의 주 기능 ID를 수직으로 완성한다.
- 명세, 테스트, OpenAPI와 구현의 일치를 완료 조건으로 사용한다.

## 결과

- 병렬 에이전트의 속도보다 추적성과 일관성을 우선한다.
- 모호한 요구사항은 코딩 전에 사용자 결정이 필요하다.
- 반복 절차는 저장소 전용 스킬과 검증 명령으로 자동화한다.
