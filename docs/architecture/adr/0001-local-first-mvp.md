# ADR-0001 로컬 우선 MVP

- 상태: accepted
- 날짜: 2026-08-10

## 배경

AWS 서버가 아직 제공되지 않았고 1차 목표는 백엔드 기능과 Swagger를 로컬에서 검증하는 것이다. AI는 다른 개발자가 1차 MVP 이후 연결한다.

## 결정

- 1차는 FastAPI, PostgreSQL, 로컬 이메일과 작업자로 실행한다.
- AWS, 운영 이메일, 외부 AI가 없어도 전체 검증이 가능해야 한다.
- 외부 연동은 교체 가능한 포트 뒤에 둔다.
- PostgreSQL을 1차부터 사용해 2차 DB 이전 위험을 줄인다.

## 결과

- 운영 배포와 관측성은 2차 작업이다.
- 로컬 어댑터와 가짜 구현이 필요하다.
- AWS 전용 코드를 1차 기능 PR에 넣지 않는다.
- 2차 연결 시 도메인 로직보다 어댑터와 설정을 교체한다.
