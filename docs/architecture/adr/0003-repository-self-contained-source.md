# ADR-0003 저장소 독립형 요구사항 기준

- 상태: accepted
- 날짜: 2026-08-10

## 배경

기능 명세 스킬과 에이전트 지침이 외부 문서 페이지 확인을 전제로 하면 연결 권한, 네트워크와 외부 서비스 상태에 따라 로컬 개발이 중단될 수 있다. 1차 MVP는 외부 계정 없이 완전히 재현돼야 한다.

## 결정

- docs/product/requirements.md를 저장소 제품 요구사항 기준으로 둔다.
- 승인된 Feature Packet을 기능 하나의 구현 계약으로 둔다.
- 외부 문서 URL은 docs/source-map.md와 Feature Packet의 선택 필드에 출처 이력으로만 보관한다.
- 외부 문서 연결 없이 명세, 구현, ERD 관리, 검증과 PR 준비를 수행할 수 있어야 한다.
- 새 외부 결정이 들어오면 같은 변경에서 로컬 기준 문서를 먼저 갱신한다.

## 결과

- 새 작업 환경에서도 저장소만으로 요구사항과 설계 경계를 복원할 수 있다.
- 외부 문서와 저장소의 중복 관리가 생기므로 동기화 변경을 명시적으로 기록해야 한다.
- 구현 중 외부 문서를 자동 조회하지 않으며 사용자가 동기화를 요청했을 때만 확인한다.
