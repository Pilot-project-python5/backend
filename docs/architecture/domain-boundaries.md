# 도메인 경계

## 인증(auth)

소유 데이터:

- 사용자 계정
- 이메일 인증 상태와 인증번호 시도
- 건강 프로필의 생년월일, 성별, 키와 몸무게
- 리프레시 세션

외부 제공:

- 인증된 user_id
- 최소 건강 프로필 조회

## 카탈로그(catalog)

소유 데이터:

- 제품과 의약품
- 카테고리
- 영양성분과 단위당 함량
- 전문가 코멘트
- 게시 상태와 외부 구매 링크

제품 정보는 시드에서 시작하며 사용자가 직접 생성하지 않는다.

## 마이케어(care)

소유 데이터:

- 회원의 복용 항목
- 구매일과 복용 시작일
- 보유 수량과 복용 계획
- 등록 시점 성분 스냅샷
- 재고 상태와 소진 예정일

care는 catalog 원본을 읽지만 기존 스냅샷을 다시 계산해 덮어쓰지 않는다.

## 알림(notification)

소유 데이터:

- 재구매와 유통기한 알림
- 화면 읽음 상태
- 이메일 발송 상태와 재시도 정보

대상, 알림 종류, 기준일과 트리거 조합의 논리 이벤트를 고유하게 관리한다. 이메일은
Notification별 전달 한 건과 수신 주소·상태·제한된 재시도를 별도 이력으로 보존한다.

## 코칭(coaching)

2차 개발 경계다. auth, care와 catalog의 공개 조회 서비스를 사용하며 해당 도메인 테이블을 직접 수정하지 않는다.
