### 데이터 호환성 결정

기존 개발 DB는 변경 전에 논리 백업하고 새 `yeongyangkkuk` PostgreSQL 스택으로
복원한다. 기존 Docker 볼륨은 삭제하지 않아 수동 복구가 가능하다. 영양소 기준 시드는
버전 자연 키로 기존 버전 UUID를 재사용해 과거 DB를 복원한 뒤에도 FK 오류 없이
새 네임스페이스의 하위 행으로 수렴한다. 인증 쿠키 이름 변경으로 기존 로그인 세션은
다시 로그인해야 한다.
