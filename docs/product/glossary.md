# 용어집

- 복용 항목: 회원이 카탈로그 제품을 선택해 구매·복용 계획과 함께 등록한 기록
- 복용 계획: 복용 시작일, 회당 복용량과 하루 복용 횟수
- 예정 섭취량: 실제 복용 기록이 아니라 복용 계획으로 계산한 일일 영양소 합계
- 단위당 함량: 정, 캡슐 또는 포 한 단위에 포함된 영양성분 양
- 총 보유 수량: 구매한 정, 캡슐 또는 포의 전체 개수
- D-day: 마지막 수량을 복용할 것으로 예상하는 날짜
- ACTIVE: 소진까지 5일보다 많이 남은 재고 상태
- LOW_STOCK: 소진 D-5부터 D-day까지의 재구매 필요 상태
- DEPLETED: D-day 다음 날부터의 수량 소진 상태
- NORMAL: 유통기한까지 5일보다 많이 남은 상태
- EXPIRING_SOON: 유통기한 D-5부터 만료일까지의 상태
- EXPIRED: 유통기한이 지난 상태
- Feature Packet: 기능 하나의 명세, 설계, 인수 조건과 작업 목록으로 구성된 구현 계약
- 시드 데이터: 로컬 개발과 테스트를 위해 반복 적재 가능한 비실사용 데이터
