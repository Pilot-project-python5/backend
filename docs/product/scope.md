# 제품 범위

## 1차 MVP 포함

### 회원과 인증

- 웹 기반 회원가입과 로그인
- 이메일과 생년월일 입력
- 6자리 이메일 인증번호
- 인증번호 유효시간 10분, 재전송 대기 60초, 최대 5회 실패
- 이메일 인증 전 로그인 차단
- HttpOnly 쿠키 기반 액세스·리프레시 토큰과 배포 환경 Secure 설정
- 액세스 15분·리프레시 14일, SameSite=Lax와 기기별 다중 세션
- 고정 14일 세션 안의 리프레시 회전·재사용 폐기와 현재 기기 로그아웃
- Access JWT·서버 세션 동시 검증, 현재 사용자·세션 만료 조회와 보호 API 공통 인증

### 전문가 큐레이션

- 활성 카테고리
- 게시된 추천 제품
- 제품·성분·전문가 코멘트·외부 구매 링크
- DB 시드 기반 제품과 의약품 카탈로그
- 전문가 소개는 프론트엔드 정적 콘텐츠

### 마이케어

- DB 카탈로그에 존재하는 영양제와 의약품 등록
- 구매일과 별도 복용 시작일
- 총 보유 수량, 회당 복용량, 하루 복용 횟수
- 제품 단위의 등록 시점 스냅샷과 미소진 재구매의 독립 구매 항목 보존
- 등록 시점의 영양제 성분 스냅샷
- 사용자 소유 활성 복용 항목 목록과 이력 보존형 소프트 삭제
- 계획 기준 일일 예정 섭취량
- 나이·성별별 CSV 영양소 기준량
- 예상 소진일과 D-day
- 의약품은 영양소 합계에서 제외

### 알림과 유통기한

- 마지막 복용 예정일을 D-day로 계산
- D-day 다음 날 DEPLETED
- 소진 D-5부터 LOW_STOCK
- 재구매·유통기한 알림을 D-5, D-3, D-1 APP_TIMEZONE(기본 Asia/Seoul)
  오전 9시에 생성
- 화면 내부 알림과 이메일
- 대상·종류·예정일·트리거 기준 논리 이벤트 중복 방지와 채널별 전달 중복 방지
- 로컬 Mailpit 이메일은 최초 포함 최대 3회, 실패마다 5분 간격 재시도
- 재고 상태와 유통기한 상태를 분리

### 개발 산출물

- 로컬 FastAPI와 PostgreSQL
- 개발·테스트 시드 데이터
- 로컬 이메일 확인과 알림 작업
- Swagger와 OpenAPI
- 단위·통합·계약·인수 테스트

## 1차 MVP 제외

- AWS 또는 운영 서버 배포
- 운영 이메일 공급자
- 추천 소식 알림 F-2.5
- AI 코칭 F-4 전체
- 의약품·영양제 상호작용 분석
- 실제 복용 여부 기록
- 카탈로그에 없는 제품 직접 입력
- 운영자 화면
- 서비스 내부 결제, 주문과 배송

## 확정이 필요한 항목

- 이메일 주소의 고유성 정책
- 유통기한 입력의 필수 여부
- 복용 계획 수정 API 제공 여부
- 삭제된 복용 항목의 복원·물리 정리와 보존 기간
- 영양소 CSV 출처, 열, 단위와 버전 규칙
- 로컬 이메일 도구와 2차 운영 이메일 공급자
