# 개발 단계

## 1차: 로컬 MVP

목표는 새 개발 환경에서 외부 계정 없이 백엔드 전 기능을 재현하는 것이다.

- FastAPI
- 로컬 PostgreSQL
- 마이그레이션
- 개발·테스트 시드
- 로컬 이메일 확인
- 로컬 알림 작업자
- Swagger와 OpenAPI
- 자동 테스트와 하네스

완료 조건은 docs/development/commands.md의 검증 인터페이스가 실제 명령으로 구현되고 make verify가 로컬에서 통과하는 것이다.

## 2차: 외부 연동

- AWS 실행 환경과 운영 PostgreSQL
- 이미지 저장소와 CDN
- 운영 이메일 공급자
- 운영 스케줄러·작업자
- 비밀정보 관리와 모니터링
- 다른 개발자가 구현하는 AI 코칭

1차에서는 2차 서비스를 직접 호출하지 않는다. 이메일, 저장소, 시간, 작업자와 AI 접근 지점은 교체 가능한 인터페이스로 둔다.
