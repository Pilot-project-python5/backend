# F-3.5 일일 섭취량 계산

## 목표

로그인 사용자가 등록한 활성 영양제 복용 계획과 등록 시점 성분 스냅샷으로 성분별
일일 예정 섭취량을 조회한다. 같은 성분은 변환 가능한 기준 단위로 환산해 합산하고,
의약품과 삭제된 항목은 계산에서 제외한다.

## 사용자 이야기

사용자로서, 여러 영양제를 함께 복용할 때 성분별로 하루에 섭취하도록 계획한 총량을
확인하기 위해 등록된 복용 계획을 자동으로 합산하고 싶다.

## 비즈니스 규칙

1. 조회는 유효한 access JWT와 서버 refresh session을 가진 로그인 사용자만 사용할
   수 있다.
2. 계산 대상은 현재 사용자 소유이면서 `deleted_at IS NULL`인 CareItem에 연결된
   영양성분 스냅샷이다. 다른 사용자와 삭제된 항목은 포함하지 않는다.
3. 일일 예정 섭취량은 스냅샷 `amount_per_unit × dose_per_intake ×
   intakes_per_day`로 계산한다.
4. 같은 nutrient_id는 Nutrient의 canonical_unit으로 환산한 뒤 하나로 합산한다.
5. G·MG·MCG는 10진 질량 단위로 정확히 상호 변환한다. IU는 IU끼리만 합산하며
   질량 단위와의 영양성분별 환산은 지원하지 않는다.
6. 스냅샷 단위와 기준 단위가 변환 불가능하면 값을 누락하거나 임의 환산하지 않고
   503 `SERVICE_UNAVAILABLE`로 실패한다.
7. MEDICATION은 F-3.2 스냅샷이 없으므로 합계에 포함하지 않는다. 성분이 없는
   SUPPLEMENT도 결과에 항목을 만들지 않는다.
8. `intake_start_date`는 F-3.7 소진 일정의 시작점이다. F-3.5는 특정 날짜의 실제
   복용 여부가 아니라 활성 **복용 계획의 일일 총량**을 계산하므로 미래 시작 계획도
   포함한다.
9. 실제 복용 기록, 총 보유 수량에 따른 소진 여부와 현재 잔량은 계산에 사용하지 않는다.
10. 계산값은 저장하지 않고 요청마다 현재 활성 CareItem과 불변 스냅샷으로 계산한다.
11. 결과는 nutrient_code ASC, nutrient_id ASC로 안정 정렬하며 Decimal 정밀도를
    보존하고 불필요한 후행 0을 제거한 문자열로 제공한다.
12. 영양성분 이름·코드·기준 단위는 Nutrient 카탈로그의 현재 표시값을 사용하되,
    함량과 원본 단위는 CareItem 등록 시점 스냅샷만 사용한다.

## 포함 범위

- 사용자 소유 활성 영양제의 일일 예정 섭취량 계산
- 동일 성분의 기준 단위 환산과 합산
- G·MG·MCG 상호 변환과 IU 동일 단위 합산
- 빈 결과·복수 구매 항목·카탈로그 함량 변경 경계 처리
- 보호 조회 API, Swagger·OpenAPI와 단위·통합·계약·인수 테스트

## 제외 범위

- 실제 복용 기록과 날짜별 복용 완료 여부
- 총 보유 수량·소진일·현재 잔량·D-day·재구매 상태 계산
- 나이·성별 영양소 기준 CSV와 기준량 대비 비율(F-3.6)
- IU와 질량 단위 사이의 영양성분별 환산
- 계산 결과 저장·이력·캐시 테이블
- 의약품 영양소 합산과 상호작용 분석
- AWS·AI 연결

## 시나리오

### 기본 흐름

- 사용자가 G·MG·MCG처럼 서로 다른 단위로 같은 성분을 가진 활성 영양제를 여러 개
  등록한 뒤 조회하면, 각 스냅샷과 복용 계획을 곱하고 기준 단위로 환산한 하나의 합계를
  받는다.
- 같은 제품의 재구매 CareItem도 독립 계획으로 계산에 기여한다.
- 카탈로그의 제품 성분 함량이 바뀌어도 기존 CareItem은 저장된 스냅샷으로 계산한다.

### 실패와 경계

- 인증하지 않은 요청은 401 `AUTH_REQUIRED`다.
- 다른 사용자의 CareItem과 소프트 삭제된 CareItem은 결과에 영향을 주지 않는다.
- 활성 성분 스냅샷이 없으면 200과 빈 nutrients를 반환한다.
- 변환 불가능한 단위 조합이나 DB 조회 실패는 503이며 일부 합계를 반환하지 않는다.
- 조회를 반복해도 데이터를 변경하지 않고 같은 입력에는 같은 결과를 반환한다.
