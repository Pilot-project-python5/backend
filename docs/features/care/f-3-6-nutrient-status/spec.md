# F-3.6 영양성분 현황

## 목표

현재 복용 계획에서 계산한 영양성분별 일일 예정량을 사용자의 계산 시점 나이·성별에
맞는 공인 기준량과 비교해 홈 화면 그래프용 데이터로 제공한다. 이 비율은 식품 섭취를
포함한 실제 영양 상태가 아니라 등록된 보충제 계획이 총 식이 기준량에서 차지하는
비율임을 계약에 명확히 표시한다.

## 사용자 이야기

사용자로서, 복용 중인 영양제가 공인된 나이·성별 기준량과 비교해 어느 정도인지 한눈에
보기 위해 성분별 예정량·기준량·단위·달성 비율을 조회하고 싶다.

## 비즈니스 규칙

1. 로그인한 현재 사용자만 조회할 수 있고 요청에서 사용자 ID나 기준일을 받지 않는다.
2. 조회 기준일은 주입한 서버 시각을 `APP_TIMEZONE`으로 변환한 날짜이며, 생년월일을
   지난 생일 기준의 만 나이로 계산한다.
3. 현재 예정량은 F-3.5와 동일하게 삭제되지 않은 영양제 복용 계획 전체를 계산한다.
   의약품, 삭제 항목과 실제 복용 여부는 포함하지 않는다.
4. 기준 원본은 보건복지부·한국영양학회의 `2025 한국인 영양소 섭취기준`이며
   애플리케이션 코드와 분리한 UTF-8 CSV로 관리한다.
5. 개인 비교에는 권장섭취량(RNI)이 있으면 RNI를 사용하고, RNI가 없고 충분섭취량(AI)이
   있으면 AI를 사용한다. 임신·수유 추가량은 1차 회원 프로필로 판별할 수 없어 제외한다.
6. 일반 `OMEGA_3`는 공식 기준의 `EPA+DHA`와 같은 개념임을 보장할 수 없으므로 임의로
   매핑하지 않는다.
7. 기준량을 찾은 성분의 비율은 `현재 예정량 / 기준량 × 100`으로 계산한다. Decimal로
   계산하고 소수 첫째 자리 문자열로 반올림하며 100%를 초과해도 자르지 않는다.
8. 기준량이 없는 성분도 현재 예정량은 반환한다. 이때 reference_available=false,
   reference_amount·reference_type·achievement_rate_percent는 null이다.
9. 결과는 nutrient_code, nutrient_id 순으로 결정적으로 정렬하고 계산 결과 자체는
   저장하지 않는다.
10. CSV는 version, source_name, source_url, published_on, nutrient_code, gender,
    age_min, age_max, reference_type, reference_amount, unit 열을 가진다.
11. 적재 전에 필수 열·허용 성별·나이 범위·양수 값·허용 단위·성분 기준 단위·중복 키·
    겹치는 나이 구간·버전 메타데이터 일관성을 검사하고 전체 파일 SHA-256을 보존한다.
12. 응답에는 기준 버전·출처·계산 기준일·만 나이·성별을 포함하며 개인 건강 관련 응답은
    `Cache-Control: no-store`를 사용한다.

## 포함 범위

- `GET /api/v1/care/nutrient-status`
- 현재 사용자 프로필의 만 나이·성별 계산
- F-3.5 일일 예정량과 버전 관리 기준량 결합
- 그래프용 현재량·기준량·달성 비율 응답
- 기준 CSV 검증·멱등 적재·버전 및 checksum 보존
- PostgreSQL 기준 버전·값 테이블과 ERD·OpenAPI·테스트

## 제외 범위

- 음식 섭취량, 실제 복용 기록과 임상적 결핍·과잉 판정
- 임신·수유 상태별 추가량
- 질량과 IU 사이 성분별 환산
- `OMEGA_3`를 `EPA+DHA`로 간주하는 임의 매핑
- 사용자가 기준 버전이나 기준일을 선택하는 기능
- 2차 기준 자동 다운로드와 외부 서비스 연동

## 시나리오

### 기본 흐름

- 사용자가 조회하면 서버가 프로필과 활성 영양제 계획을 읽고 성분별 일일 예정량을
  계산한다.
- 서버가 설정된 기준 버전에서 사용자의 만 나이·성별 구간을 선택한다.
- 정확한 기준이 있는 성분은 예정량·기준량·비율을, 없는 성분은 예정량과 기준 없음
  상태를 함께 반환한다.

### 실패와 경계

- access JWT 또는 서버 세션이 유효하지 않으면 401 `AUTH_REQUIRED`다.
- 활성 영양제 성분이 없으면 메타데이터와 빈 nutrients 배열을 200으로 반환한다.
- 생일 당일과 전날의 만 나이 경계를 주입 가능한 시계로 검증한다.
- CSV 형식·중복·겹침·단위 오류는 적재 전에 전체 적재를 거부한다.
- 설정한 기준 버전이 DB에 없거나 DB 조회·단위 변환이 실패하면 부분 결과 없이 503
  `SERVICE_UNAVAILABLE`다.
- 동일 CSV 시드를 반복 적용해도 같은 버전·값으로 수렴한다.
