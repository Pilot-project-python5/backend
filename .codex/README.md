# Codex 프로젝트 설정

이 폴더는 신뢰된 프로젝트에서 적용되는 Codex 설정과 실행 승인 규칙을 보관합니다.

- config.toml: 단일 모델 운영, 승인 정책과 샌드박스 설정
- rules/default.rules: 파괴 가능성이 있는 명령을 실행하기 전 사용자 승인 요구

모델 이름은 현재 팀에서 확정하지 않았으므로 저장소에 고정하지 않습니다. API 키, 토큰, 이메일 비밀번호와 AWS 자격증명은 이 폴더나 Git에 저장하지 않습니다.

코드베이스의 실제 검증 명령이 생긴 뒤에만 훅을 추가합니다. 존재하지 않는 명령을 호출하는 빈 훅은 만들지 않습니다.
