# 프로젝트 스킬

이 폴더는 Codex가 자동 탐색하는 저장소 전용 스킬을 보관합니다.

- specify-sdd-feature: 구현 전 기능 계약 작성
- maintain-project-erd: 데이터 변경과 로컬 ERD·마이그레이션 계획 동기화
- verify-sdd-feature: 구현과 명세의 일치 검증
- record-feature-history: 완료된 기능의 실제 구현 내용과 검증 근거 기록
- prepare-feature-pr: 기능 단위 PR 준비

스킬은 단일 Codex 모델의 반복 절차이며 서브에이전트를 사용하지 않습니다.
저장소 전체 규칙은 루트 AGENTS.md가 담당합니다.
